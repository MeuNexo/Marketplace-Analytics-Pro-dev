# Quick 260618-269: Toggle Dark/Light Mode — Summary

## One-liner

Wired next-themes ThemeProvider (attribute="class") in App.tsx and added ThemeToggle (Sun/Moon, useTheme) to Header.tsx, activating pre-existing dark CSS tokens.

## What Was Done

### Task 1: Wire ThemeProvider + ThemeToggle no Header

**src/App.tsx** — Added `import { ThemeProvider } from "next-themes"` and wrapped the entire app tree with:
```tsx
<ThemeProvider attribute="class" defaultTheme="light" enableSystem={false} disableTransitionOnChange>
```
Placed as the outermost wrapper so `.dark` class is applied to `<html>` and cascades everywhere.

**src/components/layout/ThemeToggle.tsx** (new file) — Named export `ThemeToggle`:
- Uses `useTheme()` from next-themes to read `resolvedTheme` and call `setTheme`
- Toggles between `"light"` and `"dark"`
- Shows `Moon` icon when light (click → go dark), `Sun` icon when dark (click → go light)
- `mounted` guard via `useEffect` avoids icon flash before hydration
- `variant="ghost" size="icon"` matches existing Header button style
- `aria-label="Alternar tema"`

**src/components/layout/Header.tsx** — Imported `ThemeToggle` and inserted `<ThemeToggle />` inside the right-side `<div className="flex items-center gap-1 md:gap-3 shrink-0">`, positioned before the Bell notification button. No existing items removed or reordered.
