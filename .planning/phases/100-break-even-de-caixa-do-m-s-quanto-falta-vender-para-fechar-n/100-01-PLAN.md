## Contrato de saída da RPC (interface consumida pelo plano 100-02)

Shape: `RETURNS TABLE (secao text, categoria text, total numeric, n integer)` — mesmo estilo da `get_dre_cash`, TUDO num round-trip (D-07). Linhas canônicas (nomes EXATOS — o plano 100-02 depende deles):

| secao | categoria | total | n |
|-------|-----------|-------|---|
| `saida_prevista` | `saidas_pagas` | Σ cash_outflows paid, outflow_date no mês (todos os blocos, incl. excluido e financeiro — todo pagamento é saída na régua de caixa) | count |
| `saida_prevista` | `estornos_ocorridos` | ABS(Σ net_amount<0) com COALESCE(refund_date, release_date) no mês e ≤ hoje — clone da CTE refunds_agg da get_dre_cash | count |
| `saida_prevista` | `saidas_pendentes` | Σ cash_outflows pending, outflow_date ≥ hoje E < fim do mês (cancelled NUNCA; mês futuro NUNCA — D-06a) | count |
| `saida_prevista` | `estornos_previstos` | taxa_estornos × entradas_agendadas (só sobre as agendadas: estornos de vendas novas já estão dentro da taxa_venda_para_caixa — documentar no SQL) | count agendadas |
| `saida_prevista` | `imposto_previsto_restante` | CASE: guia do mês já paga (>0) → 0; senão COALESCE(taxa_media × faturamento_mes, 0) — MESMAS CTEs da linha imposto_previsto da get_dre_cash (D-02) | n_validas |
| `entrada` | `entradas_liberadas` | base cheia igual Phase 99: Σ CASE WHEN net_amount>0 THEN net_amount ELSE ABS(net_amount) END, release_date no mês e ≤ hoje | count |
| `entrada` | `entradas_agendadas` | Σ net_amount, release_date > hoje e < fim do mês (dado real MP, sync 45d) | count |
| `taxa` | `taxa_liquido_bruto` | fração 0-1 medida: Σ liquido base-cheia ÷ Σ gross_amount, janela 90d por release_date ≤ hoje (ref. ~0,78 — MEDIR, nunca constante fixa) | count janela |
| `taxa` | `taxa_estornos` | fração 0-1 medida: ABS(Σ net<0 por régua refund) ÷ liquido base-cheia, mesma janela 90d (ref. ~0,10-0,15) | count estornos janela |
| `taxa` | `taxa_venda_para_caixa` | taxa_liquido_bruto × (1 − taxa_estornos) (D-03) | — |
| `taxa` | `lag_liberacao_dias` | inteiro (como numeric) estimado dos dados, método documentado no SQL (ver Task 1) | count base |
| `ritmo` | `vendas_7d_media_diaria` | Σ receita_bruta de orders paid/shipped/delivered com data_pedido::date nos últimos 7 dias ÷ 7 (D-05) | count orders |
| `alerta_recorrencia` | {category do cash_outflows} | {amount repetido} | nº de meses futuros em que a dupla aparece (D-06b) — 0..N linhas |

NULL em `total` é permitido só nas taxas sem dado suficiente (janela vazia); a lib pura do 100-02 trata.
