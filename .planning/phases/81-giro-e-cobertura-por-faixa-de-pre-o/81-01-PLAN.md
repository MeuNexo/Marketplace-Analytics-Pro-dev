       - computeCoberturaFaixa(estoqueAtual, giro): retorna number | null seguindo esta PRECEDÊNCIA
         exata (empate resolvido por estoque primeiro, per decisão de CONTEXT):

           b) estoqueAtual <= 0 → 0 (esgotado);
           c) giro == null ou giro <= 0 → null (sem giro);
           d) senão Math.floor(estoqueAtual / giro).
         O resultado é dia INTEIRO arredondado para baixo; a formatação "<1d" fica na UI (81-02).

    4. Estender os tipos e o retorno:
       - FaixaPreco ganha quatro campos: diasNaFaixa (number), giroDia (number | null),
         coberturaDias (number | null), baixaConfianca (boolean). baixaConfianca é

       - No map que constrói cada FaixaPreco, calcular giroDia via computeGiroFaixa(unidades,
         diasNaFaixa) e coberturaDias via computeCoberturaFaixa(opts.estoqueAtual ?? null, giroDia).

       Em computeVeredicto, localizar a faixa do preço vigente (isPrecoAtual) e usar r.estoqueAtual +
       a coberturaDias dessa faixa para montar uma frase determinística (template sobre números, sem
       LLM), no espírito de: preço atual em R$, estoque de N unidades, dura ~Y dias. Regras de borda:
       coberturaDias 0 com estoque > 0 → dizer que dura menos de 1 dia; estoque 0 → dizer que está
       sem estoque; sem faixa atual / estoque null / coberturaDias null → coberturaTexto null (a UI
       simplesmente não renderiza a linha). Reusar os formatters brl/pct já existentes.

    Não introduzir dependências novas. Não tocar em niceStep, weightedPercentile, classificarSaude
