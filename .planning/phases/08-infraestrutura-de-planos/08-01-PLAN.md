<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated → organization_plans | Usuários autenticados podem ler planos da sua org; apenas owner pode alterar |
| authenticated → sync_quota_daily | Usuários autenticados podem ler contagem de quota; escrita vedada (service_role only) |
| service_role → sync_quota_daily | Edge functions incrementam sync_count sem passar por RLS |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Elevation of Privilege | organization_plans INSERT/UPDATE | mitigate | RLS policy "organization_plans insert/update" usa get_org_role = 'owner'; members e viewers não podem alterar planos |
| T-08-02 | Tampering | sync_quota_daily INSERT/UPDATE | mitigate | Nenhuma policy de escrita para authenticated; apenas service_role (edge functions) pode incrementar sync_count |
| T-08-03 | Information Disclosure | organization_plans SELECT | accept | Tier e limites são informação operacional não sensível; acesso restrito a membros da org via is_org_member |
| T-08-04 | Tampering | seed migration | accept | Migration roda com service_role no deploy; ON CONFLICT DO NOTHING é idempotente e não destrói dados existentes |
</threat_model>
