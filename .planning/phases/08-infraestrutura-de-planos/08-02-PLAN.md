  <how-to-verify>
    Execute as seguintes queries no SQL Editor do Supabase (https://supabase.com/dashboard/project/gionpsuunfkkzzjdubfy/sql) ou via psql:

    1. Verificar estrutura de organization_plans:
       SELECT column_name, data_type, column_default, is_nullable
       FROM information_schema.columns
       WHERE table_schema = 'public' AND table_name = 'organization_plans'
       ORDER BY ordinal_position;
       ESPERADO: organization_id (uuid, PK), plan_tier (USER-DEFINED), sync_interval_minutes (integer), history_days (integer), created_at (timestamptz), updated_at (timestamptz)

    2. Verificar estrutura de sync_quota_daily:
       SELECT column_name, data_type, column_default, is_nullable
       FROM information_schema.columns
       WHERE table_schema = 'public' AND table_name = 'sync_quota_daily'
       ORDER BY ordinal_position;
       ESPERADO: organization_id (uuid), date (date), sync_count (integer, default 0)

    3. Verificar RLS habilitado:
       SELECT tablename, rowsecurity
       FROM pg_tables
       WHERE schemaname = 'public' AND tablename IN ('organization_plans', 'sync_quota_daily');
       ESPERADO: rowsecurity = true para ambas as tabelas

    4. Verificar seed:
       SELECT COUNT(*) as orgs_sem_plano
       FROM public.organizations o
       LEFT JOIN public.organization_plans op ON op.organization_id = o.id
       WHERE op.organization_id IS NULL;
       ESPERADO: 0 (zero organizações sem plano)

    5. Verificar planos enterprise:
       SELECT plan_tier, sync_interval_minutes, history_days, COUNT(*) as total
       FROM public.organization_plans
       GROUP BY plan_tier, sync_interval_minutes, history_days;
       ESPERADO: plan_tier = 'enterprise', sync_interval_minutes = -1, history_days = -1 para todos os registros

    6. Verificar idempotencia do seed (executar no SQL Editor):
       INSERT INTO public.organization_plans (organization_id, plan_tier, sync_interval_minutes, history_days)
       SELECT id, 'enterprise', -1, -1 FROM public.organizations ON CONFLICT (organization_id) DO NOTHING;
       ESPERADO: executa sem erro, retorna "INSERT 0" (zero novas linhas)
  </how-to-verify>
  <acceptance_criteria>

    - Zero organizações sem plano após o seed (query 4 retorna 0)
    - Todos os registros em organization_plans têm plan_tier = 'enterprise', sync_interval_minutes = -1, history_days = -1
    - Executar o seed novamente retorna "INSERT 0" sem erros
