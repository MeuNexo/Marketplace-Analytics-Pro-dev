OrderRecord (já definido em src/lib/analysis/types.ts):
- { id, price, quantity, order_date, ml_user_id, item_id, title, brand }

DB → OrderRecord mapping (de RESEARCH §Data Access Gap):
- id ← row.id
- price ← row.preco_unit ?? 0
- quantity ← row.quantidade ?? 1
- order_date ← row.data_pedido ?? ""
- ml_user_id ← row.ml_user_id
- item_id ← row.item_id
- title ← row.titulo ?? ""
- brand ← null  (coluna inexistente em orders — sempre null)

Filtros obrigatórios na query:
- .eq("organization_id", orgId)
- .eq("ml_user_id", mlUserId)
- .eq("item_id", itemId)
- .gte("data_pedido", dateFrom)
- .lte("data_pedido", dateTo)
- .in("status", ["paid", "shipped", "delivered"])
- order by data_pedido asc
