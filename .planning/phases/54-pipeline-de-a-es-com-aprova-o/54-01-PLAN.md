<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated user (JWT) → consultor-actions EF | Caller de uma org tentando executar ação de outra org (cross-tenant) |
| EF (service_role) → ML API (write irreversível) | Execução duplicada/concorrente da mesma ação aprovada (TOCTOU) |
| EF → ml_tokens | Buscar token da org errada → escrever no ML de outra org (IDOR) |
| EF → action_audit_log | Resposta ML grande estourando o INSERT de auditoria |
| EF → ML API | Estado do ML mudou desde a proposta (preço alterado externamente) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-54-01 | Tampering | claim_approved_action / execução dupla | mitigate | Gate atômico é o 1º statement após auth/TTL: `claim_approved_action` 0 linhas = 409 ANTES de tocar o ML; nunca SELECT-then-UPDATE |
| T-54-02 | Elevation (IDOR) | consultor-actions + ml_tokens | mitigate | Owner-check via `get_org_role` na `action.organization_id`; token lookup de 2 colunas `ml_user_id` + `organization_id`; ação fora do escopo → 403/404 |
| T-54-03 | Tampering | proposta obsoleta executada | mitigate | Pre-flight re-lê o ML e compara com `current_value`: no_op se no alvo, conflict/failed se divergiu; TTL 48h para `approved` não executado |
| T-54-04 | Repudiation | action_audit_log | mitigate | INSERT por transição (`actor_id`, de→para, ts) imutável (sem GRANT UPDATE/DELETE, Phase 52); `executed_at`/`approved_by` |
| T-54-05 | DoS | action_audit_log.detail | mitigate | `trimDetail` corta corpo ML a ≤4KB antes do INSERT (Pitfall 4) |
| T-54-06 | Info Disclosure | access_token ML | mitigate | Token nunca logado nem retornado; refresh inline sem expor secret (Pattern B no env) |
| T-54-07 | DoS/Availability | ML rate limit (429) | accept→mitigate | Retry com `Retry-After` em 429 + backoff em 5xx (PUT idempotente); falha definitiva só após 3 tentativas, registrada no audit |
| T-54-08 | Tampering | estados executing/done/failed forjados pelo cliente | mitigate | RLS (Phase 52) bloqueia authenticated nesses estados; só a EF service_role move para eles |
</threat_model>
