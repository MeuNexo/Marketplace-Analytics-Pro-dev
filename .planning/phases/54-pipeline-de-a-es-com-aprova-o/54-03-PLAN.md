## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| non-owner → aba Fila/Histórico | Usuário sem permissão tentando ver/agir na fila de aprovação |
| owner (UI) → approve | Clique de aprovação dispara execução irreversível no ML |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-54-14 | Information Disclosure | aba Fila/Histórico para não-owner | mitigate | Render condicionado a `orgRole === 'owner'` na UI; RLS owner-only (Phase 52) é a barreira real por trás |
| T-54-15 | Tampering (acidental dupla-ação) | botão Aprovar | mitigate | `AlertDialog` de confirmação antes de approve; o gate atômico no executor (54-01) impede execução dupla mesmo com cliques repetidos |
| T-54-16 | Tampering | proposta obsoleta aprovada sem aviso | mitigate | Badge de staleness (>24h) na Fila + pre-flight/TTL no executor (54-01) bloqueia no servidor |
| T-54-17 | Repudiation | quem aprovou não é rastreável | mitigate | approve grava `approved_by`/`approved_at` (54-02) + audit no executor (54-01) |

(Sem instalação de pacotes — zero deps novas em todo o v8.0 → sem Package Legitimacy Gate.)
