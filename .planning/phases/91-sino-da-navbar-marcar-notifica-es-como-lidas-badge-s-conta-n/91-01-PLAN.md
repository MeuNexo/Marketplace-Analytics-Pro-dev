<objective>
Transformar o badge vermelho do sino de atendimento (`AtendimentoBell`) de "total de pendências vivas" para "novidades ainda não vistas". Abrir o sino marca tudo como visto e zera o badge; ele volta a subir só quando chega algo genuinamente novo via o refetch de 45s de `useAtendimentoPendencias`. A lista e o header do popover continuam mostrando o TOTAL de pendências — o "lido" afeta só o alerta, nunca a fila de trabalho.

Purpose: Reduzir ruído do sino. Hoje o badge nunca zera enquanto houver pendência viva; o operador perde a noção do que é NOVO. Implementa BELL-01 (badge = não-vistos), BELL-02 (abrir zera + persiste) e BELL-03 (prune de keys resolvidas).

Output: lib pura testável (`src/lib/bellSeen.ts` + testes), hook `useBellSeen` (localStorage por org), e fiação do `AtendimentoBell`. Client-only — sem backend/EF/RPC/migration/nova dependência.
</objective>

## Artifacts this phase produces

**New pure lib — `src/lib/bellSeen.ts`** (React-free, testável em vitest):
- `computeUnread(items, seenKeys)` — nº de `items` cuja `key` NÃO está em `seenKeys`. `items: { key: string }[]`; `seenKeys: readonly string[]`. Retorna `number`.
- `mergeAndPruneSeen(seenKeys, items)` — recebe o conjunto visto atual + as pendências vivas; retorna o novo conjunto visto = **merge das keys atuais** e **prune das keys que não estão mais entre `items`**. Resultado líquido = exatamente as keys presentes em `items` (dedupadas). Assinatura: `(seenKeys: readonly string[], items: { key: string }[]) => string[]`.

**New test — `src/lib/bellSeen.test.ts`** cobrindo os 5 cenários (ver Task 1 `<behavior>`).

**New hook — `src/hooks/useBellSeen.ts`**:
- Assinatura: `useBellSeen(items: { key: string }[], isLoading: boolean) => { unreadCount: number; markAllSeen: () => void }`
- Lê `orgId` internamente via `useOrganization()` (`currentOrg?.id ?? null`).
- Chave de localStorage: **`bell-seen:{orgId}`** (valor = array JSON de keys já vistas).
- Semeadura na 1ª montagem sem registro: badge começa em 0 (semeia com as keys atuais assim que `!isLoading`).
- `markAllSeen()`: aplica `mergeAndPruneSeen` no set atual + `items` e persiste.

**Modified — `src/components/layout/AtendimentoBell.tsx`**: badge passa a usar `unreadCount`; `Popover onOpenChange(true)` chama `markAllSeen()`; header/lista inalterados (continuam usando `count`/`items`).

**Formato da chave de localStorage:** `bell-seen:{orgId}` — ex.: `bell-seen:7f615df7-...`. Sem orgId (org nula) → hook não persiste e reporta `unreadCount = 0`.
