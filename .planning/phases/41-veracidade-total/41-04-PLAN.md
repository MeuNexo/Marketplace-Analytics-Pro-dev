# Plan 41-04 — Card Custos vira DRE Mensal (pedido de Wesley 2026-06-12, mid-phase)

## Objective

Refazer o card "Custos" de /vendas como **DRE mensal** espelhando a fatura do Mercado Livre: todas as linhas vêm do mês (não do filtro diário) — receita do mês, grupos de tarifas do billing real, CMV do mês, impostos do mês → margem do mês. Referência visual: tela "Tarifas" do ML (print de Wesley).

**Decisão de produto (locked):** o card é SEMPRE mensal. Usa o mês do período filtrado (`billingMonth` já derivado de `currentFrom`); filtros curtos ("Hoje", "7d") continuam afetando os DEMAIS cards, mas o card DRE mostra o mês daquele filtro com label claro do mês.

## Grupos de tarifas (mapear de ml_billing_monthly.charges por type)

| Grupo (label na UI) | Types |
|---|---|
| Tarifas de venda | CVVML, CVVPRC, CVVFNU (prefixo CVV*, exceto CVAF) |
| Tarifas de envios no Mercado Livre | CFFE, CXDE, CFFI, CXDED |
| Taxas de parcelamento | CFONPN |
| Campanhas de publicidade | PADS |
| Tarifas Full (coleta/armazenagem/inconformidade) | CFCBE, CFBA, CFPB, CFWA |
| Impostos cobrados pelo ML (DIFAL) | CDIFAL |
| Programa de afiliados | CVAF |
| Outras tarifas | qualquer type não mapeado (CESM, CDSDB, ...) — bucket fallback, nunca dropar |

Valores somados com sinal (estornos negativos subtraem). Total de tarifas = soma de todos os grupos.

## Estrutura da DRE no card

```
DRE do Mês — Junho/2026                       [badge: billing ML | estimado]
Receita do mês (vendas pagas)                              R$ X
(−) Tarifas de venda                                       R$ X
(−) Envios Mercado Livre                                   R$ X
(−) Taxas de parcelamento                                  R$ X
(−) Publicidade                                            R$ X
(−) Tarifas Full                                           R$ X
(−) Impostos ML (DIFAL)                                    R$ X
(−) Afiliados / Outras tarifas                             R$ X
  = Total de tarifas ML                                    R$ X
(−) CMV do mês                                             R$ X
(−) Impostos próprios (regime fiscal)                      R$ X
═ Lucro do mês                                R$ X   (margem Y%)
```
