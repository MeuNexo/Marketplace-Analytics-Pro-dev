Semáforo (3-state, D-04, reused verbatim from `mcoHealth.ts` / Phase 83, CVD-safe per `dataviz`):

|---|---|---|

## Card Layout (Claude's Discretion, resolved)

Single `Card` (shadcn), placed with `mt-6` below the existing chart `ResponsiveContainer` block, inside `PrecoPraticadoReport.tsx`, reacting to the same `selectedId`/`selectedSku`/`currentFrom`/`currentTo`/`incluirAds` state already in the component. Structure top→bottom:

1. **Header row:** `Target` icon (accent) + "Detalhamento de MCO" (`text-sm font-semibold`) + semáforo `Badge` (variant per `mcoHealthRole`, shows `pctFmt(mcoPct)` — never color alone) + period label (reuse existing granularity/date-range label already shown above the chart, `text-xs text-muted-foreground`, right-aligned).
2. **Waterfall block:** vertical list of rows, one per component, in this fixed order (top→bottom = the actual P&L cascade, matches the conversation's manual example and the D-02 field order): Receita/un → (−) CMV/un → (−) Comissão/un → (−) Frete/un → (−) Impostos/un → **= MC/un** (subtotal, slightly heavier weight/border-top divider) → (−) Ads/un (only rendered when `incluirAds` toggle is ON, per canonical ref) → **= MCO/un** (final row, bold, semáforo-colored value). Each row = reused `Row` component (moved to module scope per RESEARCH Code Examples, `k`/`v`/`dotColor` pattern already in `ChartTooltip`) showing `R$ X,XX` and `(Y,Y%)` side by side on the same line (per Specific Ideas: "(−) CMV: R$ 59,00 (42,1%)"), 8px vertical rhythm between rows (`space-y-2`).
3. **Meta MCO% row:** inline editable field, label "Meta MCO%:" + `InlineEditCell`-style input (same onBlur/Enter pattern as `MLAnuncios.tsx`, no debounce, no new component) pre-filled with the customized value if one exists for this `item_id`+`sku`, else showing the default band reference (`MCO_SAUDAVEL_PCT.green` = 9, i.e. "usar padrão (≥9%)" as placeholder/helper text below the input in `text-[10px] text-muted-foreground`). Validation inline (client-side, mirrors the DB `CHECK`): reject 0, negative, and >100 with a toast (`sonner`, same convention as `ReplenishmentParamsDialog`/`ml_tax_config` per accumulated project decisions), never silently clamp.
4. **Recommendation block (always visible, D-08):** two lines, each icon + label + headline number (`text-xl font-bold tabular-nums`):
   - "Preço mínimo para a meta: **R$ Y,YY**" (or "— meta impraticável com os custos atuais" in `text-destructive text-xs` when `reversePrice` returns `null`)
   - "ACOS-alvo da campanha: **Z,Z%**" (or "— meta inatingível mesmo sem ads" in `text-destructive text-xs` when `acosMeta <= 0`)
5. **Warning footer (conditional, reuses exact existing copy pattern from lines 828-838 of this same file):** `AlertTriangle` icon + `text-[10px] text-warning`, one line per active condition (`custoAusente`, `impostoAusente`) — never a new warning style.

No new modal/dialog, no new page route. Single-item scope only (no side-by-side comparison, per Deferred Ideas).
