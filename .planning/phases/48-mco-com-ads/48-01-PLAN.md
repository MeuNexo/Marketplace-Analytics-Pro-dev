O corpo é exatamente o SQL canônico do 48-RESEARCH.md linhas 588-687 — transcrever sem omitir nenhum campo.

    Estrutura obrigatória:
    1. CTE `orders_side`: agrega `public.orders` por `o.item_id` com `MAX(titulo)`, `MAX(sku)`, `MAX(listing_type)`, `SUM(receita_bruta) AS receita`, `SUM(custo_unit*quantidade) AS cmv`, `SUM(comissao)`, `SUM(frete)`, `SUM(tax_amount) AS impostos`, `lucro = SUM(receita_bruta − custo_unit*quantidade − comissao − frete − tax_amount)` com COALESCE em cada parcela, `COUNT(*) AS pedidos`, `SUM(quantidade) AS unidades`, `BOOL_OR(custo_unit IS NOT NULL) AS has_cmv`. Filtro: `o.organization_id = p_org_id AND o.ml_user_id = ANY(p_user_ids) AND o.status IN ('paid','shipped','delivered') AND o.data_pedido::date BETWEEN p_from AND p_to AND o.item_id IS NOT NULL`. `GROUP BY o.item_id`.
    2. CTE `ads_side`: agrega `public.ml_ads_products_cache` por `a.item_id` com `MAX(a.title) AS ads_title`, `COALESCE(SUM(a.spend),0) AS ads_spend`, `COALESCE(SUM(a.attributed_orders),0) AS ads_attributed_orders`. Filtro: `a.organization_id = p_org_id AND a.ml_user_id = ANY(p_user_ids) AND a.date BETWEEN p_from AND p_to`. `GROUP BY a.item_id`.
    3. SELECT final com `FULL OUTER JOIN ads_side a USING (item_id)` (D-11: itens ads-only devem surgir), com `COALESCE(o.item_id, a.item_id) AS item_id`, `COALESCE(o.titulo, a.ads_title) AS titulo`, todos os campos operacionais via COALESCE 0, `ads_spend`/`ads_attributed_orders` via COALESCE 0, `lucro_pos_ads = COALESCE(o.lucro,0) − COALESCE(a.ads_spend,0)`, `lucro_pct_pos_ads = CASE WHEN receita>0 THEN ROUND((lucro − ads_spend)/receita*100, 2) ELSE NULL END`, e `ads_no_sale = (COALESCE(a.ads_spend,0) > 0 AND COALESCE(a.ads_attributed_orders,0) = 0)`. `ORDER BY COALESCE(o.receita, 0) DESC`. SEM LIMIT (MCO-01 — sem truncamento; SECURITY DEFINER já evita o limite PostgREST de 1000 linhas).

    Encerrar com `GRANT EXECUTE ON FUNCTION public.get_margin_with_ads_by_product(UUID, TEXT[], DATE, DATE) TO authenticated;` (mesmo padrão de `get_margin_by_product`, chamada pelo browser via JWT do usuário).
