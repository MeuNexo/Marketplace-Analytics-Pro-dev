Exportar `validateUploadFile(file: { name: string; type: string; size: number }): { ok: true } | { ok: false; error: string }` que verifica, nesta ordem, nome não-vazio, nome ≤125 chars e casando a regra de chars seguros, tipo ∈ ALLOWED_UPLOAD_TYPES, e size ≤ MAX_UPLOAD_BYTES, retornando uma mensagem PT-BR curta e específica por falha (ex.: "Formato não suportado — use JPG, PNG ou PDF", "Arquivo acima de 5 MB", "Nome de arquivo inválido").
