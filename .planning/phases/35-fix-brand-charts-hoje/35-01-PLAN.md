# Plan 35-01 — fix-brand-charts-hoje

## Goal
Brand charts e KPI cards carregam para "Hoje" mesmo quando `marca = null` em orders.
Auto-sync tem retry quando sync retorna 0 pedidos.

## Root Causes
1. `useMLOrdersByBrand` filtra `rows.filter((r) => r.marca)` — descarta todos os pedidos sem marca → hasData=false mesmo com orders no DB
2. `useAutoRecalc` adiciona key ao `firedRef` antes de saber se o sync teve sucesso — bloqueia retry se retornou 0 pedidos
3. Erros de `sync-ml-orders` são silenciosos — não há feedback ao usuário/console

## Tasks

### Task 1: Fix useMLOrdersByBrand — incluir pedidos sem marca como "Sem Marca"
File: src/hooks/useMLOrdersByBrand.ts
- Usar `rows` (não `rowsWithBrand`) como base de agregação
- Pedidos sem `marca` → grupo "Sem Marca"
- `hasData` = `rows.length > 0` (não depende de marca)

### Task 2: Fix useAutoRecalc — retry logic + error visibility
File: src/hooks/useAutoRecalc.ts
- NÃO adicionar key ao `firedRef` antes do sync
- Após sync: se `orders_synced = 0`, não marcar como fired (permitir retry)
- Se sync retornar erro HTTP, logar no console.error
