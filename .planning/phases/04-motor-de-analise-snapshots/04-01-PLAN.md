  <behavior>
    Função exportada: computeAnalysis(orders: OrderRecord[], periodDays: number): AnalysisResult

    MOTOR-01 — buildPriceCurve(orders, periodDays):
    - Agrupar por price (chave numérica, comparar com precisão de 2 casas)
    - units = sum(order.quantity) por grupo
    - gmv = price × units
    - activeDays = count de order_date únicos por grupo (string comparison é suficiente)
    - dailyAvg = units / periodDays  (dividir pelo período TOTAL, não activeDays)
    - totalUnits = sum de todos os units; totalGmv = sum de todos os gmv
    - volShare = units / totalUnits
    - gmvShare = gmv / totalGmv
    - Ordenar resultado por price ASC

    MOTOR-02 — findPriceGmv(curve):
    - Sort por dailyAvg DESC, depois por gmv DESC como desempate
    - Retornar curve[0].price

    MOTOR-03 — findPriceMargin(curve, priceGmv, periodDays):
    - gmvUnits = units do bucket priceGmv
    - threshold = gmvUnits × 0.15
    - Candidatos: preços acima do priceGmv com units >= threshold
    - Se candidatos existem: retornar o maior price dos candidatos
    - Fallback: raw = priceGmv × 1.10; roundUpTo99(raw)
      - roundUpTo99: Math.ceil(raw) → se não termina em .99, subir para próximo .99
        Ex: 66.00 → 65.99? Não: deve ser o .99 ACIMA do inteiro floor.
        Algoritmo correto: floor = Math.floor(raw); se raw <= floor + 0.99 → floor + 0.99; senão (floor+1) + 0.99
        Mais simples: Math.ceil(raw - 0.99) + 0.99 — arredonda para o menor x.99 >= raw
        Verificar contra casos de teste: raw=66.00 → 65.99? Não, 65.99 < 66.00, logo 66.99
        raw=65.45 → 65.99 pois 65.99 >= 65.45; raw=65.99 → 65.99; raw=66.01 → 66.99

    MOTOR-04 — findPriceNeutral(curve, priceGmv, priceMargin):
    - weightedAvg = Σ(price × units) / Σ(units)  sobre TODOS os buckets
    - Candidatos reais: buckets com priceGmv <= price <= priceMargin
    - Se candidatos existem: retornar o price cuja distância a weightedAvg é mínima
      Empate: escolher o preço mais baixo
    - Fallback: mid = (priceGmv + priceMargin) / 2
      Candidatos de arredondamento: [roundTo(mid, .99), roundTo(mid, .90)]
      Escolher o mais próximo de mid
      roundTo(value, ending): Math.floor(value) + ending se esse resultado >= value, senão Math.floor(value) + 1 + ending

    MOTOR-05 — computeElasticity(curve, priceGmv, priceMargin):
    - Se priceMargin == priceGmv → { elasticityPct: 0, elasticityClass: 'baixa' }
    - dailyAvgGmv = bucket de priceGmv .dailyAvg
    - dailyAvgMargin = bucket de priceMargin .dailyAvg (se fallback: interpolar linearmente ou aceitar 0)
    - deltaPrice = priceMargin - priceGmv
    - deltaVol = dailyAvgGmv - dailyAvgMargin
    - lossPerReal = deltaVol / deltaPrice
    - pct = (lossPerReal / dailyAvgGmv) × 100
    - Classificar: pct <= 0.70 → 'baixa'; pct <= 1.30 → 'media'; pct <= 2.00 → 'alta'; else 'extrema'
  </behavior>
