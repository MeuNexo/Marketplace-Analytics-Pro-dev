<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → stripe-checkout EF | client sends tier enum + org_id; EF re-validates owner + resolves price server-side |
| browser → Supabase (RLS) | /planos reads subscriptions/organization_plans; cannot write tier |
| browser cache query → cache tables | history window must hold even if client requests older dates |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44C-01 | Elevation of Privilege | non-owner reaches /planos | mitigate | RoleRoute + roleAccess /planos = OWNER_ONLY (same as /sellers, /integracoes); EF re-checks owner server-side regardless |
| T-44C-02 | Tampering | client claims success to fake tier | mitigate | ?status=success only triggers refetch; tier truth is organization_plans written by the webhook, not the redirect (RESEARCH anti-pattern) |
| T-44C-03 | Information Disclosure | reading another org's subscription | mitigate | useSubscription is org-scoped (.eq organization_id) under member-SELECT RLS |
| T-44C-04 | Information Disclosure | history beyond tier via client | mitigate | frontend clamp here + RESTRICTIVE RLS-by-date / RPC clamp from 44-01 (server is the real ceiling — Pitfall 7) |
| T-44C-05 | Tampering | spoof price_id from client | mitigate | client sends only the tier enum; price_id resolved server-side in the EF from tier_prices (T-44B-06) |
</threat_model>
