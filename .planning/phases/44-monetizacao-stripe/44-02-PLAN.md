<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Stripe → stripe-webhook (public EF) | Untrusted POST; authenticity proven only by HMAC signature |
| browser owner → stripe-checkout | Authenticated; must be the org owner |
| EF → Stripe API | Uses sk_test secret; must never reach the browser |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44B-01 | Spoofing | webhook signature forgery | mitigate | constructEventAsync with whsec; unsigned/forged → 400 (Pattern 2) |
| T-44B-02 | Tampering | replay / duplicate events | mitigate | insert-first dedupe on billing_events.event_id (23505→200); RPC idempotent + order-tolerant (Pitfall 3) |
| T-44B-03 | Elevation of Privilege | non-owner starts checkout for an org | mitigate | get_org_role owner gate before sessions.create (403 otherwise) |
| T-44B-04 | Tampering | cross-org tier change | mitigate | client_reference_id/metadata = organization_id; webhook binds tier to that org only; checkout sets it server-side |
| T-44B-05 | Information Disclosure | STRIPE_SECRET_KEY / whsec leak | mitigate | secrets only in EF env; stripe imported only in Deno EF, never frontend bundle; errors never echo secret (Pitfall 8) |
| T-44B-06 | Tampering | price_id spoofing in checkout | mitigate | price_id resolved server-side from tier_prices by tier (client sends tier enum, not price_id); webhook re-derives price from Stripe subscription object |
| T-44B-07 | Spoofing | open redirect via success/cancel URL | mitigate | success/cancel/return URLs built from server-side APP_ORIGIN, never request Origin |
| T-44B-SC | Tampering | esm.sh stripe install | mitigate | stripe pinned @22 (RESEARCH Package Legitimacy: OK, official, no postinstall); imported only in Deno EF |
</threat_model>
