  <behavior>
    - getVendaDiaria(snapshot):
      - Se snapshot.strategy é 'gmv' | 'neutral' | 'margin', seleciona o preço correspondente (priceGmv / priceNeutral / priceMargin), procura no priceCurve o bucket cujo preço, comparado em centavos inteiros (Math.round(price × 100)), bate com o target, e retorna { dailyAvg: bucket.dailyAvg, estrategia, fallback: false }.
      - Se snapshot.strategy === null, usa priceGmv como target, estrategia = 'gmv', fallback: true.
      - Se nenhum bucket bater (defensivo), retorna dailyAvg = 0 com fallback: true e estrategia = 'gmv'.
    - getPctFull('gmv') === 0.80; getPctFull('neutral') === 0.60; getPctFull('margin') === 0.50.
    - calcularCompra(snapshot, inputs, multiplicador):
      - vendaDiariaEstrategia = getVendaDiaria(snapshot).dailyAvg
      - coberturaAlvo = vendaDiariaEstrategia × multiplicador × inputs.diasCobertura
      - compraRecomendada = Math.max(0, Math.ceil(coberturaAlvo) − inputs.estoqueTotal)  // COMP-03
      - sugestaoFull = Math.min(Math.ceil(coberturaAlvo × getPctFull(estrategia)), inputs.estoqueTotal)  // COMP-04
      - Retorna o CompraResult preenchido com estrategiaUsada e fallbackUsed propagados.

    Testes (compraUtils.test.ts):
    - COMP-03 caso normal: vendaDiaria=10, mult=1.5, dias=30, estoqueTotal=100 → coberturaAlvo=450, compraRecomendada=350.
    - COMP-03 clamp negativo: vendaDiaria=1, mult=1.0, dias=10, estoqueTotal=100 → compraRecomendada=0.
    - COMP-04 gmv → ceil(coberturaAlvo × 0.80), neutral → 0.60, margin → 0.50.
    - sugestaoFull respeita teto estoqueTotal (não excede).
    - Fallback: snapshot.strategy === null → estrategiaUsada='gmv', fallbackUsed=true, usa priceGmv para casar dailyAvg.
    - Float equality: priceCurve com preço terminado em .99 (ex.: 49.99) é encontrado mesmo quando target=49.99 (compara via centavos inteiros).
  </behavior>
